# Кейсорока 🐦

Telegram-бот, который приносит на хвосте идеи для бизнеса: необычные модели монетизации, реальные кейсы компаний и стартапы с потенциалом.

Юзернейм бота: [@itmoftmi_pae_bot](https://t.me/itmoftmi_pae_bot)

Слоган: «Приношу на хвосте идеи для бизнеса».

## Что умеет бот

- `/start` — знакомство и главное меню.
- `/digest` — подборка из 3–5 свежих материалов из RSS.
- `/random` — случайная идея из уже собранной базы.
- `/interests` — ключевые слова для фильтра новостей.
- `/saved` — материалы, которые вы положили «в гнездо».
- Ежедневная рассылка в заданное время (по умолчанию 09:00 по Москве), пока программа запущена.

Все эти действия также доступны через кнопки меню — команды знать не обязательно.

## Какие файлы за что отвечают

| Файл | Назначение |
| --- | --- |
| `bot.py` | Весь код бота: меню, RSS, база данных, рассылка |
| `requirements.txt` | Список библиотек Python, которые нужно установить |
| `.env.example` | Образец настроек без настоящего токена |
| `.env` | Ваши секретные настройки (создаёте сами, в Git не попадает) |
| `.gitignore` | Список файлов, которые не нужно отправлять в Git |
| `keysoroka.db` | База SQLite: появляется сама после первого запуска |

RSS-адреса лежат в начале `bot.py` в списке `RSS_SOURCES`. Их можно менять в одном месте.

Источники первой версии:

- [TechCrunch](https://techcrunch.com/feed/) — стартапы и технологии
- [Inc.](https://www.inc.com/rss/homepage.xml) — предпринимательство
- [Fast Company](https://www.fastcompany.com/latest/rss?truncated=true) — инновации и бизнес-идеи
- [Entrepreneur](https://www.entrepreneur.com/latest.rss) — бизнес-идеи и практика
- [VC.ru](https://vc.ru/rss) — русскоязычные кейсы и стартапы

Если одна лента недоступна, бот продолжает работать с остальными.

## Что нужно заранее

1. Компьютер с macOS.
2. Python 3.11 или новее (у вас уже есть Python 3.13).
3. Виртуальное окружение `.venv` (у вас уже создано).
4. Токен Telegram-бота от [@BotFather](https://t.me/BotFather).

## Как получить токен у BotFather

1. Откройте Telegram и найдите пользователя `@BotFather`.
2. Отправьте `/newbot` или, если бот уже создан, `/token`.
3. Скопируйте длинную строку вида `123456789:AAH...`. Это и есть `BOT_TOKEN`.
4. Никому её не отправляйте и не вставляйте в код.

## Установка и запуск на macOS

Откройте Терминал и перейдите в папку проекта:

```bash
cd /Users/alina/Documents/keysoroka
```

Включите уже существующее виртуальное окружение:

```bash
source .venv/bin/activate
```

После этого в начале строки терминала обычно появляется `(.venv)`.

Установите библиотеки:

```bash
pip install -r requirements.txt
```

Создайте файл настроек из образца:

```bash
cp .env.example .env
```

Откройте файл `.env` в Cursor и замените `your_telegram_bot_token` на настоящий токен:

```
BOT_TOKEN=вставьте_сюда_токен_от_BotFather
TIMEZONE=Europe/Moscow
DIGEST_TIME=09:00
```

Сохраните файл.

Запустите бота:

```bash
python bot.py
```

Если всё хорошо, в терминале появится сообщение вроде «Кейсорока взлетает…». Окно терминала закрывать нельзя: пока программа работает, бот отвечает в Telegram и может отправлять утреннюю рассылку.

Остановить бота: нажмите `Control + C` в терминале.

## Как проверить, что всё работает

1. Найдите в Telegram бота `@itmoftmi_pae_bot` и нажмите **Start** (или отправьте `/start`).
2. Должно прийти приветствие Кейсороки и кнопки меню.
3. Нажмите **📰 Свежие находки**. Через несколько секунд придёт вступление и 3–5 отдельных новостей со ссылками.
4. У любой новости нажмите **⭐ В гнездо**, затем **⭐ Моё гнездо** — материал должен быть в избранном.
5. В гнезде нажмите **🗑 Убрать из гнезда** — запись исчезнет из избранного.
6. Нажмите **🔎 Мои интересы**, затем «Изменить список» и отправьте, например: `стартапы, маркетинг`.
7. Снова откройте свежие находки: бот постарается выбрать материалы по этим словам. Если совпадений мало, он честно скажет об этом.
8. Нажмите **🧹 Очистить интересы** — фильтр снимется.
9. Нажмите **💡 Случайная идея** — придёт один материал из базы.
10. Нажмите **🔔 Настройка рассылки** и проверьте включение/выключение.
11. Чтобы убедиться, что данные не пропадают: остановите бота (`Control + C`), запустите снова и откройте «Моё гнездо» и интересы.

Ежедневную рассылку удобно проверять так: в `.env` поставьте `DIGEST_TIME` на ближайшие 2–3 минуты, перезапустите бота и подождите. Не забудьте вернуть `09:00`.

## Частые вопросы

**Бот пишет, что токен не задан.**  
Проверьте, что файл называется именно `.env`, лежит в папке `keysoroka`, и в нём нет пробелов вокруг знака `=`.

**Новости не приходят.**  
Одна RSS-лента могла временно не ответить. Подождите и нажмите «Свежие находки» ещё раз. Если интернета нет, бот не сможет летать за материалами.

**Рассылка не пришла в 09:00.**  
Бот должен быть запущен в это время. Если компьютер выключен или терминал закрыт, рассылка не отправится. Это ограничение учебной версии, отдельный сервер не нужен.

## Ограничения первой версии

- Нет нейросети: тексты берутся из RSS, бот не переводит статьи и не выдумывает детали.
- Английские заголовки остаются на английском.
- Рассылка работает только пока запущена программа на вашем компьютере.
- Фильтр интересов ищет слова в заголовке и кратком описании, а не во всей статье.
- Некоторые зарубежные сайты могут блокировать автоматические запросы — тогда бот просто пропустит эту ленту.
- Нет аккаунтов, облачной базы и админ-панели: всё хранится в локальном файле `keysoroka.db`.
