**О проекте:** Кейсорока собирает бизнес-новости из RSS, позволяет фильтровать их по интересам и отраслям, сохранять статьи и получать дайджесты. Написана на Python с `python-telegram-bot`; данные хранятся в SQLite.

**Запуск локально:** установить зависимости командой `pip install -r requirements.txt`, создать `.env` с переменной `BOT_TOKEN` по образцу `.env.example`, затем запустить `python bot.py`. Файлы `.env` и `*.db` не публикуются в репозитории.
